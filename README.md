# TradPlus Meta Audience Network Adapter Swift Package

Swift Package Manager support for the TradPlus Meta Audience Network adapter (15.12.0).

## Installation

```text
https://github.com/tradplus/TradPlusAdSDK-SPM-Meta.git
```

```swift
.package(url: "https://github.com/tradplus/TradPlusAdSDK-SPM-Meta.git", exact: "15.12.0")
```

Third-party dependency: Meta Audience Network `6.21.1`.

## Notes

- This package automatically resolves `TradPlusAdSDK` 15.12.0.
- Add `-ObjC` to the app target's `Other Linker Flags` if required.
